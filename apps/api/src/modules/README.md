# Modul API yang akan ditambahkan

- `buyers/` — data pembeli dan validasi kontak.
- `transactions/` — checkout, penahanan stok, status, dan rekonsiliasi.
- `payments/` — permintaan QRIS dan webhook payment gateway.
- `tickets/` — UUID, QR Code, dan pengiriman e-tiket.
- `checkin/` — validasi dan pemindaian tiket.
- `reports/` — rekap transaksi/kehadiran dan ekspor CSV/XLSX.

Tiap modul dapat berisi route/controller, service, validasi, dan pengujian.
